💊 MediFind – Medicine Availability Finder

MediFind is a full-stack web application that helps users find medicines available at nearby pharmacies. Users can search for medicines, check availability and prices, find nearby pharmacies, and request or reserve medicines.

🚀 Features
🔍 Search for medicines
📍 Find nearby pharmacies
💊 Check medicine availability and price
📏 View pharmacy distance
🗺️ Location and map-based pharmacy search
📄 Upload prescriptions
🔔 Medicine availability notifications
💰 Find lower-cost medicine alternatives
🚨 Emergency medicine search
👤 User dashboard
🏪 Pharmacy dashboard
🔐 Admin dashboard

⚙️ Installation and Setup
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
cd medicalfind
2. Install frontend dependencies
npm install
3. Start the frontend
npm run dev

The frontend will run on:

http://localhost:5173
4. Start the backend

Open another terminal:

cd server
npm install
npm run dev

The backend API runs on:

http://localhost:5000
🔗 API

The frontend communicates with the backend using REST APIs.

Example:

/api/health
/api/search
/api/nearby
🎯 Project Objective

The main objective of MediFind is to make it easier for people to locate medicines from nearby pharmacies without visiting multiple stores to check availability.
